# NXP AIM India 2025 - Warehouse Treasure Hunt Solution

### NXP AIM competiton description
The NXP AIM India 2025 (Artificial Intelligence in Mobility) competition is a nationwide challenge by NXP Semiconductors that invites engineering students across India to design and test intelligent autonomous mobility solutions using simulation and modern robotics technologies. Participants address real-world mobility challenges by building autonomy, perception, and control algorithms using LiDAR and cameras in Gazebo simulations, gaining hands-on experience in AI/ML, ROS 2, embedded systems, and autonomous navigation while showcasing industry-relevant, sustainable mobility solutions. The challenge tests skills in ROS2 development, path planning with Nav2, sensor fusion, and real-time decision making.

The core problem statement of the NXP AIM India 2025 challenge is to develop an autonomous mobile robotics solution that can efficiently navigate and perform tasks in a simulated environment—such as warehouse inventory management—by integrating camera and LiDAR sensor data to enable robust perception, obstacle avoidance, and navigation. Teams are expected to design algorithms that allow their robot to interpret sensor inputs, plan safe paths, and complete assigned missions quickly with minimal penalties, showcasing effective real-time decision-making and control in complex scenarios.
